### 2.2 Contrato do Estado Central e Contexto (`src/types/tournament.ts`)

```typescript
export interface Team {
  id: string;
  name: string;
  players: string[]; // 10 posições fixas
}

export type MatchStatus = 'PENDING' | 'FINISHED';

export interface Match {
  id: string;
  roundNumber: number;
  roundTime: string;
  field: 'Campo 1' | 'Campo 2';
  homeTeamId: string;
  awayTeamId: string;
  homeScore: number | null;
  awayScore: number | null;
  status: MatchStatus;
}

export interface KnockoutMatch {
  id: 'sf1' | 'sf2' | 'third_place' | 'final';
  title: string;
  field: 'Campo 1' | 'Campo 2';
  time: string;
  homeTeamId: string | null;
  awayTeamId: string | null;
  homeScore: number | null;
  awayScore: number | null;
  homePenalties: number | null;
  awayPenalties: number | null;
  winnerTeamId: string | null;
  loserTeamId: string | null;
  status: MatchStatus;
}

export interface TournamentState {
  teams: Team[];
  matches: Match[];
  knockoutMatches: KnockoutMatch[];
  version: number;
  lastUpdated: string;
}
```

## 4. Matriz de Casos de Testes Exaustiva

| Categoria | Cenário de Teste | Entrada | Resultado Esperado |
|---|---|---|---|
| Happy Path | Computar vitória simples | Time A 3 x 1 Time B | Time A +3 pts, +1 V, +2 SG; Time B +0 pts, +1 D, -2 SG |
| Happy Path | Computar empate | Time A 2 x 2 Time B | Ambos +1 pt, +1 E, 0 SG |
| Happy Path | Ordenação decrescente por pontos | Equipes com pontuações distintas | Equipe com mais pontos no topo da lista |
| Happy Path | Desempate por número de vitórias | Time A (6 pts, 2 V) vs Time B (6 pts, 1 V) | Time A classificado à frente de Time B |
| Happy Path | Desempate por confronto direto | Empate em pts, V, SG e GP; Time A venceu Time B no turno | Time A classificado à frente de Time B |
| Happy Path | Avanço automático para Semifinais | 21 jogos finalizados na 1ª fase | SF1 = 1º x 4º; SF2 = 2º x 3º preenchidos |
| Happy Path | Avanço da Semifinal para Final | SF1 venceu Time A, SF2 venceu Time C | Final = Time A x Time C; 3º Lugar = Time B x Time D |
| Boundary | Partida pendente (ainda não jogada) | Placar `homeScore: null, awayScore: null` | Status `PENDING`, nenhuma pontuação atribuída |
| Boundary | Mata-Mata empatado no tempo normal | Semifinal 1 x 1 | Exigir preenchimento de pênaltis antes de definir vencedor |
| Boundary | Importação de backup com estrutura válida | JSON exportado pelo próprio app | Estado restaurado com 100% de integridade |
| Error | Partida com placar negativo | Input `-1` | Entrada rejeitada ou sanitizada |
| Error | Empate nos pênaltis | Pênaltis 3 x 3 | Rejeição: disputa de pênaltis deve ter um vencedor definido |
| Error | Importação de backup corrompido | String aleatória ou JSON com formato inválido | Erro amigável retornado, estado local intacto |
