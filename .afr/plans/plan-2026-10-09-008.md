# Posicionamento da Barra de Abas Abaixo do Header (Sub-Header Superior) — Plano de Implementação

> **Para workers agênticos:** SUB-SKILL OBRIGATÓRIA: use `afr-superpowers:executing-plans` para execução das etapas. Passos usam sintaxe de checkbox (`- [ ]`) para rastreamento canônico.

**Objetivo:**
1. Mover a barra com as 6 abas (`Navigation`) da base da tela para o topo, posicionando-a imediatamente abaixo do `Header` (atuando como um segundo header estático / sub-header).
2. Eliminar completamente o footer na base da tela, zerando qualquer risco de sobreposição pelos botões virtuais de navegação do celular (Android: Voltar, Início, Recentes; ou barras de ferramentas de navegadores móveis).
3. Atualizar o estilo visual do `Navigation` para layout superior: borda inferior (`border-b border-[#1E2D44]`), indicador de aba ativa posicionado na base do botão (`bottom-0`), e sem dependência de paddings de rodapé.
4. Manter o miolo `<main>` rolando livremente logo abaixo da barra superior de abas (`flex-1 overflow-y-auto overscroll-contain px-3.5 pt-3.5 pb-8`).

**Critérios de Aceitação Vinculados:**
- AC-012: Barra de abas superior como Sub-Header fixo no topo.
- AC-013: Rolagem independente do conteúdo fluindo abaixo das abas.
- AC-014: Estrutura superior unificada e base da tela totalmente desobstruída.
