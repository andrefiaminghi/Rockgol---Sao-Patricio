# Controle de Súmula para Árbitros e Juízes — Plano de Implementação

> **Para workers agênticos:** SUB-SKILL OBRIGATÓRIA: use `afr-superpowers:subagent-driven-development` ou `afr-superpowers:executing-plans` para implementar este plano task-por-task. Passos usam sintaxe de checkbox (`- [ ]`) para rastreamento.

**Objetivo:** Implementar o controle oficial de súmulas para os árbitros do torneio RockGol 2026, com registro de autores de gols, cartões disciplinares, suspensões automáticas, sincronização condicional de placares, ranking de artilharia, nova aba "Súmula" e exportação modular em WhatsApp e PDF.

**Arquitetura:** Expansão reativa do estado global no TypeScript (`TournamentState.scoresheets`), implementação de serviço de domínio puro (`scoresheetService.ts`) para regras de negócio de gols e cartões, componentes mobile ergonômicos (`ScoresheetTab.tsx` e `ScoresheetModal.tsx`) e evolução dos geradores de exportação (`pdfExportService.ts`).

**Stack técnica:** React 19, TypeScript, Tailwind CSS, Lucide React, jsPDF, Vitest.

**Em projetos afr:**
- Camadas: Types (`src/types/`), Services (`src/services/`), Components (`src/components/`), Testes (`tests/unit/`).
- Testes: Vitest com cobertura rigorosa TDD (Red-Green-Refactor).
- Commits: Conventional Commits em `pt-BR` via `afr-git:conventional-commit`.
